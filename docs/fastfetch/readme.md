# devsimsek's dotfiles - fastfetch

Welcome to my fastfetch config! Which does absolutely nothing except for showing you a pretty devsimsek text combined with some system information. I only use it for fun, and I don't even know why I have it installed. But if you want to use it, feel free to copy the config from this repo and put it in your own fastfetch config directory.

## Change logo

To change the logo displayed in fastfetch like i did, is to change a single line in the config file. You can find the config file in your fastfetch config directory, which is usually located at `~/.config/fastfetch/config`. Open the file and look for the line that starts with `logo=`. Change the value to the path of your desired logo file. For example:

```bash
logo=~/.config/fastfetch/mylogo.txt
```
