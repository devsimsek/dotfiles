# devsimsek's dotfiles - ghostty

Ghostty is my choice of terminal emulator. It is a lightweight and fast terminal emulator that supports modern features like true color, ligatures, and transparency. Also it is shipped in a way that it doesn't require you to alter with your configuration. So, what have I changed? Great one; theme!

## Creating themes in Ghostty

Well to put it simply you just create a new directory called `ghostty/themes` in the `~/.config/ghostty/` directory and create a `theme` file in that directory. The `theme` file is where you define your theme's colors and other settings. See their config to learn more about setting your own theme in ghostty.

## Rose Pine

Originally Ghostty do provide a highly customisable theme version of Rose Pine, but I wanted to continue with my own version of it. So I created a new theme called `rose-pine` (which you'll see if you pull this repo). I am happy with it, you should be too.
